# CC Notify: Claude Code 알림 오버레이 (macOS)

VS Code 창을 여러 개 켜두고 Claude Code를 돌리다 보면, 어느 창이 허용을 기다리는지 놓쳐서 작업이 한참 멈춰 있곤 합니다. CC Notify는 이 문제를 해결하는 작은 오버레이 앱입니다.

- 세션마다 화면 우측 가장자리에 작은 카드가 붙어 있습니다.
- Claude가 허용을 기다리거나, 질문을 하거나, 작업을 마치면 소리와 함께 보고 있는 화면 테두리가 살짝 번쩍이고, 카드가 펼쳐지며 무슨 일인지 보여줍니다.
- 카드를 클릭하면 해당 세션의 창이 앞으로 나옵니다. 허용과 거부는 그 창에서 직접 결정합니다.

상세 문서: 문제정의와-솔루션.md, 기능-명세.md, 제작-파이프라인.md

## 설치

```bash
npm install
bash scripts/install-hooks.sh
```

install-hooks.sh는 `~/.claude/settings.json`에 hook 8개(SessionStart, PreToolUse, PostToolUse, PermissionRequest, UserPromptSubmit, Notification, Stop, SessionEnd)와 플랜 사용량 게이지용 statusline(hooks/statusline.sh)을 등록합니다. statusline 스크립트는 화면에 아무것도 표시하지 않는 데이터 통로이며, 직접 만든 statusline이 이미 있으면 덮어쓰지 않고 알려만 줍니다. 기존 설정은 보존되고, 쓰기 전에 `settings.json.bak`으로 백업됩니다. hook은 새로 시작하는 Claude Code 세션부터 적용됩니다.

## 실행

```bash
npm start
```

메뉴바에 🔔 아이콘으로 상주하고 Dock에는 표시되지 않습니다. 메뉴바 메뉴에서 음소거, 상시 글로우, 로그인 시 자동 시작을 설정할 수 있습니다.

패키징된 앱을 만들려면:

```bash
npm run build
open "dist/mac-arm64/CC Notify.app"
```

## 카드 읽는 법

카드 색이 곧 상태입니다. 파란 계열은 내 차례, 보라는 Claude 차례라고 기억하면 됩니다.

| 색 | 의미 | 하면 되는 일 |
|---|---|---|
| 주황 | 허용 대기. 어떤 도구를 실행하려는지(bash 명령 전문, 파일 경로 등)가 카드에 표시됩니다 | 카드를 클릭해 창으로 가서 허용 또는 거부 |
| 파랑 | 입력 대기. 작업 중 Claude가 질문을 했습니다 | 카드를 클릭해 창으로 가서 답변 |
| 초록 | 작업 완료. 턴에 걸린 시간이 함께 표시됩니다 | 다음 요청을 보내면 됩니다 |
| 보라 숨쉬기 + 스피너 | Claude가 작업 중입니다 | 기다리면 됩니다 |
| 옅은 파랑 | 유휴. 세션이 입력을 기다리며 쉬고 있습니다 | 없음 |

알림이 해소되는 조건:

- 주황과 파랑: 해당 창에서 응답해 도구가 실행되거나 새 입력을 보내면 사라집니다.
- 초록: 해당 세션 창을 앞으로 가져오는 순간(카드 클릭이든 직접 창 전환이든) 확인한 것으로 보고 사라집니다.
- 응답이 없으면 1분 간격으로 최대 5회까지 소리와 번쩍임으로 다시 알려줍니다. 자리를 오래 비워도 소음이 되지 않도록 5회에서 멈춥니다.

## 사용법

- Claude Code 세션이 시작되면 카드가 자동으로 생깁니다. 앱보다 먼저 시작된 세션도 10초 간격 프로세스 스캔으로 찾아냅니다. 다만 hook 등록 전에 시작된 세션은 알림이 보장되지 않으므로, 완전한 동작을 원하면 그 세션을 재시작하세요.
- 카드 클릭: 해당 세션의 창이 앞으로 나옵니다. 세션 폴더 이름과 상위 폴더 이름까지 후보로 창 제목을 매칭하므로, 워크스페이스 하위 폴더에서 실행한 세션도 워크스페이스 창을 찾아갑니다. VS Code가 아닌 곳(Claude 데스크톱 앱, iTerm, Terminal)에서 실행한 세션은 해당 앱을 활성화합니다.
- 알림 카드의 ✕ 버튼(마우스를 올리면 우상단에 나타남): 창 전환 없이 알림만 끕니다. 다른 화면을 보던 중 일단 치우고 싶을 때 사용합니다.
- 카드 드래그: 아무 곳이나 잡고 끌어서 세로 위치를 바꿀 수 있고, 위치는 디렉토리별로 저장됩니다.
- 카드 우클릭 메뉴: 카드 닫기(세션은 유지), 세션 종료(claude 프로세스와 셸에 종료 신호를 보내 VS Code 터미널 탭까지 닫힘)를 선택할 수 있습니다.
- 지금 보고 있는 창의 세션 카드는 접히지 않고 펼쳐진 채 유지됩니다.
- 4시간 동안 이벤트가 없는 세션 카드는 흐려집니다.

## 컨트롤 패널

카드들 위에 항상 떠 있는 작은 패널입니다.

- 화살표를 누르면 모든 카드를 한 번에 펼치거나 접습니다.
- 펼치면 투명도 슬라이더가 나타납니다. 알림이 뜬 카드는 투명도와 무관하게 선명하게 표시됩니다.
- 플랜 사용량 게이지: Claude Code의 /usage 화면과 같은 값(세션, 주간 한도 %)을 보여줍니다. 세션과 주간 수치는 Claude Code의 공식 statusline 기능으로 받으므로 세션이 활동하는 동안 실시간으로 갱신되고, 모델별 주간 수치(Fable 등)는 비공식 사용량 API를 15~25분 무작위 간격(시간당 최대 3회)으로 조회해 함께 표시합니다. 접힌 상태에서도 세션 %는 항상 보입니다. 사용량이 일정 단위(세션 5%, 주간과 모델별 10%)를 넘을 때마다 패널이 잠깐 펼쳐지며 알려주고, 80%와 95%를 넘을 때는 소리와 테두리 번쩍임으로 알립니다. 모델별 수치는 조회가 실패하면 조용히 빠지며 나머지 표시에는 영향이 없습니다. 조회가 사용량 API의 호출 제한(429)에 걸리면 그날은 조회를 멈추고 다음날 0시에 자동 재개합니다 (앱을 껐다 켜도 유지).

## 권한

카드 클릭으로 창을 앞으로 가져오는 기능은 macOS 손쉬운 사용(접근성) 권한이 필요합니다. 첫 클릭 시 시스템이 권한을 요청하며, 시스템 설정의 개인정보 보호 및 보안, 손쉬운 사용에서 이 앱(개발 실행 시 Electron)을 허용하면 됩니다.

## 주의사항과 한계

- 창 매칭은 창 제목에 세션 폴더(또는 상위 폴더) 이름이 포함되는지로 판단합니다. 같은 폴더 이름의 프로젝트가 여러 개 열려 있으면 다른 창이 선택될 수 있습니다.
- 이 앱은 알림 전용입니다. 허용과 거부 입력은 항상 해당 창에서 직접 합니다.
- 세션 종료는 SIGTERM을 보내는 방식이라 진행 중이던 작업이 그 자리에서 중단되며 되돌릴 수 없습니다.
- Claude Code가 내부적으로 띄우는 백그라운드 데몬(claude daemon run, bg-pty-host)은 창이 없는 보조 프로세스라 세션으로 취급하지 않습니다. VS Code가 업데이트로 재시작될 때 이런 데몬이 고아로 남아도 유령 카드가 생기지 않습니다.

## 설정 파일

`~/Library/Application Support/claude-code-notification/config.json` (npm start와 패키징된 CC Notify.app 모두 같은 경로)

| 키 | 기본값 | 설명 |
|---|---|---|
| port | 48923 | 로컬 이벤트 수신 포트 (hook 쪽은 환경변수 CC_NOTIFY_PORT) |
| muted | false | 알림 소리 끄기 |
| idleGlow | true | 알림 미해소 시 옅은 상시 글로우 유지 |
| soundPath | /System/Library/Sounds/Glass.aiff | 알림 소리 파일 |
| cardY | {} | 디렉토리별 카드 세로 위치 (자동 관리) |
| opacity | 1 | 카드 투명도 (0.2 ~ 1, 슬라이더로 조절) |
| usagePollBlockedUntil | 0 | 사용량 API 429 차단 시 다음 조회 허용 시각 (자동 관리) |

## 제거

1. 메뉴바에서 종료.
2. `~/.claude/settings.json`의 hooks에서 notify.sh가 포함된 항목을 모두 삭제하고, statusLine이 statusline.sh를 가리키면 그 키도 삭제 (또는 백업 settings.json.bak으로 복원).
